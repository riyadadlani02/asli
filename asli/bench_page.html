asli test bench

Your voice, a real speech API, and a verdict on where it decided you had finished. Keys stay on the machine running this page; nothing is sent anywhere except the providers you tick.

How to read every result on this page

LIVE
Streamed to the vendor just now, from this machine, in real time. Every timestamp came off that vendor's socket.
STORED
The receipt of an earlier live run, re-opened from results/bench/. Same data, not re-run.
MOCK
The offline energy VAD. No vendor, no transcript. Checks the bench works; says nothing about any product.
PREDICTION
Arithmetic from a sample's known pause, shown before a run. A guess to check against, not a measurement.

Passcode

This bench is shared over the network, so it asks for the passcode its owner set.

What did you say? (optional)

With this, the bench checks whether the agent had the number when it replied — not just whether it heard it eventually. Leave it empty and it only judges where the turn ended. It never guesses a truth for you.
