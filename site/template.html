A pause is not
the end of a thought.

A caller says matlab (“umm”), pauses, then gives the number. A silence timer can treat the pause as the end and make the agent answer too soon. The one-call replay shows the exact moment it happens.

05our proposal

Use meaning when you can.
Use a guardrail when you cannot.

Semantic turn detection is the cleanest fix. Providers without it can hold a turn when its last words clearly sound unfinished.

where the hesitation fallsturns the timer cutrule holdsstill cut

The word-based guardrail catches some unfinished turns without delaying every call. It cannot safely decide every sentence, which is why semantic detection is better where available.

13the tool

Test your own agent.

The harness is the product. These numbers are one reproducible run.

uv venv --python 3.12 && uv pip install -e ".[agent]"
python tests/test_asli.py                 # 17 checks. no keys, no network

echo "SARVAM_API_KEY=..." >> .env
uv run asli check                         # one call, raw event stream
uv run asli sweep --suite pir --agent sarvam --pause-ms 700
uv run asli conv  --agent sarvam --gate 500      # what the agent holds when it replies
uv run asli real  --corpus corpus/GV_Dev_5h/Audio --agent sarvam
uv run asli fit   --corpus corpus/GV_Dev_5h/Audio # pause distribution + what to set the gate to

14turnbench

A pause needs a
benchmark, not a guess.

TurnBench is a separate, offline harness for measuring whether an agent speaks before a caller resumes, or waits after a true yield.

Kept separate from this study. It uses local fixtures and recorded event streams—no provider calls, no cross-language leaderboard, and no claimed results until matched data arrives.
